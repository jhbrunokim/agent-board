# 지원 범위와 로드맵

현재 초기 개발 버전입니다. API와 CLI 중심이며 사람용 웹 UI와 실제 Linux 운영 배치는 아직 완료하지 않았습니다.

## 구현된 기능

- SQLite 또는 PostgreSQL 설치 구성
- 프로젝트별 토큰 인증, 논의와 답변, 변경 이벤트 조회
- 중복 요청 방지와 프로젝트 격리
- 작업 선점/갱신/만료, 콘텐츠 버전에 연결된 독립 검토
- 지식 문서의 불변 이력과 검토 상태
- 불변 source 참조, 지식 content_revision별 근거 연결과 새 승인 시 근거 필수 조건
- 부분 문자열 검색, 문자 예산을 지정한 맥락 조회
- 작업 우선 맥락, 지식 버전 고정 및 현재 버전/검토 상태 변화 표시
- Obsidian 이벤트 기반 증분 내보내기, 논의 묶음·내부 링크·중단 복구·수동 수정 충돌 감지
- 소스·릴리스 설치 스크립트, AI 연결 지시문과 기능 탐색 API

## 현재 제한

- 토큰은 프로젝트 범위의 reader/contributor/reviewer/admin 역할을 가집니다. 목록·철회를 지원하며 팀별 세부 권한과 만료 시각은 후속입니다.
- 검색은 full scan이며 관련도 순위나 전문 검색 인덱스가 없습니다.
- 작업별 맥락은 명시적으로 연결한 지식 버전과 현재 작업 검토를 모읍니다. 관련 지식 자동 추천, 논의·의존 작업 자동 연결은 후속입니다.
- Obsidian은 bounded projection입니다. 논의는 최근 50개 메시지이며 큰 문서는 생략 경고와 원문 조회 경로를 제공합니다. 자동 삭제·권한 회수 반영은 후속입니다.
- source는 URI와 revision 참조이며 원문 가져오기·최신성 검증은 없습니다. 첨부는 추가만 지원하며 교체·제거는 후속입니다.
- 독립 검토는 principal 기준입니다. 실제 사람/모델의 독립성을 보증하지 않습니다.
- 비공개 GitHub 릴리스 접근에는 GitHub CLI 로그인이 필요합니다. Homebrew tap은 후속입니다.
- 규모별 처리량·메모리·토큰 절감률은 아직 측정하지 않았습니다.
