# 지원 범위와 로드맵

현재 초기 개발 버전입니다. API와 CLI 중심이며 사람용 웹 UI와 실제 Linux 운영 배치는 아직 완료하지 않았습니다.

## 구현된 기능

- SQLite 또는 PostgreSQL 설치 구성
- 프로젝트별 토큰 인증, 논의와 답변, 변경 이벤트 조회
- 중복 요청 방지와 프로젝트 격리
- 작업 선점/갱신/만료, 콘텐츠 버전에 연결된 독립 검토
- 지식 문서의 불변 이력과 검토 상태
- 부분 문자열 검색, 문자 예산을 지정한 맥락 조회
- Obsidian 단방향 내보내기, 수동 수정 파일 충돌 감지
- 소스 설치 스크립트, AI 연결 지시문과 기능 탐색 API

## 현재 제한

- 토큰은 단일 프로젝트 전체 읽기/쓰기 권한입니다. 세부 역할·팀 권한과 토큰 철회 CLI는 후속입니다.
- 검색은 full scan이며 관련도 순위나 전문 검색 인덱스가 없습니다.
- 맥락 조회는 검색 결과를 크기로 제한합니다. 작업 관계 기반 우선순위는 아직 없습니다.
- Obsidian은 전체 ID 페이지를 읽고 변경 파일만 씁니다. 이벤트 기반 증분 수집, 논의별 문서 묶음, 자동 삭제 및 권한 회수 반영은 후속입니다.
- 구조화된 source 객체와 첨부 증거는 아직 없으며 body/comment에 근거를 기록합니다.
- 독립 검토는 principal 기준입니다. 실제 사람/모델의 독립성을 보증하지 않습니다.
- Homebrew tap과 사전 빌드 release는 아직 발행하지 않았습니다.
- 규모별 처리량·메모리·토큰 절감률은 아직 측정하지 않았습니다.
